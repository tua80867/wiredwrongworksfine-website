# Channel branding baseline

The first website frame uses the channel's existing public artwork, retrieved November 8, 2026 from https://www.youtube.com/@WiredWrongWorksFine.

- `public/assets/channel-logo.jpg`: channel avatar, 900px original.
- `public/assets/channel-banner.jpg`: channel banner, desktop crop provided by YouTube.
- Project thumbnails: public channel videos `TwndRI4nDes`, `tEn8pLCm1H4`, and `lU2XFtADcf8`.

The homepage uses a cream background, navy text, warm orange links, and yellow accents drawn from the artwork. System fonts avoid additional font-service requests. Assets are stored locally rather than hotlinked.

Featured projects are curated links, not a live YouTube feed. The planned Snap Circuits catalog is explicitly marked as in planning. No account, analytics dashboard, or catalog search is presented as available. The original private analytics utility description, policy text, policy URLs, and Cloudflare beacon are retained.

Styles are shared by the homepage and policy pages. Layout changes at 950px and 650px. Navigation wraps on small screens without JavaScript; keyboard focus, a skip link, image descriptions, and reduced-motion support are included.
